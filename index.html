BoxTopaz Draw Bridge
Privacy policy

Updated October 26, 2026 · Extension version 0.2.0

This policy covers the custom BoxTopaz Draw Bridge browser extension. It does not cover the optional local web companion, Box, or the separately installed Topaz software.

Purpose and activation

The extension relays handwriting from a Topaz signature pad to the Draw signature field on configured Choctaw Nation Box Sign document pages. The user activates the extension from the browser toolbar and starts capture. The signer reviews the drawing and chooses whether to adopt it and complete the Box transaction.

Information processed

The extension reads the active tab's URL to verify that it is an HTTPS signing-document page on choctawnation.app.box.com. It locates the Draw canvas and inspects its pixels to check whether the canvas already contains ink. It reads tablet dimensions, connection/capture status, pen events, and handwriting stroke coordinates through the separately installed official Topaz extension and native bridge. Handwriting used as a signature may be personally identifying.

During capture, the extension observes relevant page interactions and tab/window lifecycle events so it can stop capture when appropriate. It does not query browsing history, extract the PDF or signing document's text, read passwords, request Box API credentials, or implement analytics or advertising.

Use and sharing

Information is used to connect the pad, scale handwriting to the visible Draw field, relay strokes, show capture status, and stop capture. Coordinates and protocol responses are processed temporarily through browser memory and DOM messages. Stroke input is handed to the Box page's drawing component. If the signer adopts or submits the drawing, Box processes the signing transaction under its own terms and policies.

The extension uses the official Topaz extension, native bridge, and driver to interact with the pad. Those components process capture data separately from this custom extension. Box and Topaz have their own privacy practices. This policy does not replace them.

The custom extension has no developer-operated data collection endpoint, network upload implementation, telemetry, remote script loading, advertising, or sale of user data. It does not use handwriting for profiling or identity verification. It relays drawing input and does not attach Topaz biometric evidence or a certificate to the Box document. User data is used only for the extension's stated capture purpose, and is not used to determine creditworthiness or for lending.

Storage and stopping

The custom extension does not create signature files or write signature data to persistent browser storage. Temporary coordinate state is used during capture. Stop requests terminate capture and request that the native capture buffer be cleared. This does not claim secure erasure of browser/operating-system memory or control retention by the vendor components.

The drawing remains in the Box page until changed through Box's own controls. Stopping capture does not delete a signature already placed or submitted in Box. Box handles document storage and signing records. The extension stops on its Stop control, applicable page/tab/window changes, or a two-minute limit; capture errors may require reloading the page.

Choices and contact

The user can stop capture, clear the drawing through Box, decline to adopt it, or disable/uninstall the custom extension where organizational policy permits.
